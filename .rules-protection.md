# 🛡️ JUST1PLAY MANDATORY FIREBASE ARCHITECTURE & SECURITY CONTRACT

CRITICAL SYSTEM INSTRUCTION: DO NOT OVERWRITE OR WEAKEN THESE RULES.
Any feature addition, refactor, or deployment MUST preserve and adhere to these security constraints.

## 1. MEDIA PERMISSIONS CONTRACT
- **Social Wall Photos:** All authenticated members can upload and read images (`image/*`, max 15MB) to `/posts/{postId}/...`.
- **Videos for Regular Members:** Standard members MUST ONLY attach external video URLs (YouTube, Hudl, Vimeo, TikTok, Instagram). They NEVER get write access to upload raw video binaries to Firebase Storage.
- **Raw Video Uploads (`video/*`):** STRICTLY restricted to Admins (`request.auth.token.admin == true` or `isAdmin == true`). Max 250MB.
- **Social Wall Posts (Firestore):** All authenticated members can create posts under `/posts/{postId}`. Reads are public.

## 2. REPOSITORY SOURCE OF TRUTH
- Firestore Rules file: `firestore.rules`
- Storage Rules file: `storage.rules`
- Config file: `firebase.json`

When writing code or deploying features, always verify that `firestore.rules` and `storage.rules` remain intact and match this contract.
